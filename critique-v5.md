# Critique v5: deep debug pass (Oct 4, 2026)

Every page and link was crawled, and every button and flow was exercised, on three engines:
- **Android:** Pixel 7, Chromium.
- **iPhone:** iPhone 13, WebKit.
- **Desktop:** 1440×900, Chromium.

All share, print and clipboard calls were stubbed, and Supabase calls were faked, so nothing was posted. The test scripts live outside the repo, in the box scratch folder.

| Suite | What it covers |
|---|---|
| Crawl | 436 pages: every main page and variant, all `/talks/`, `/q/` and `/i/` share pages, topics, study for each of the 23 conferences (2015–2026), and all 240 speaker pages. Checks: JS errors, console errors, failed requests, 404s, horizontal overflow, clipped text, NaN/undefined/null text, missing accessible names, slow loads. |
| Click fuzz | Every visible control on 25 pages × 3 engines. |
| Studio matrix | 242 combinations × 2 engines (every look, every size × layout, every animation, palette × font), plus older-talk, insight and promo cards in every size. Checks that the canvas isn't blank. |
| Flows | Search queries (including `<script>`, blank, and nonsense input), study search with every conference, topic and speaker filter, talk notes saved and shown on My Conference, comment submit, a 40-tap quiz click-through, plan checkboxes surviving a reload, lessons (4 modes × conferences × talks, plus print media), group links, insight spotlight on every speaker, moderation (every tab and action, mocked), live wall. |
| Path home | Every page type at 390×844 on iPhone and Android: a visible, labeled way home at the top and after scrolling. |
| Older suites | qa, explorer, search, speakers, live, quote step, chips, sharing, video. |

## Findings by severity (all fixed)

### Critical
| # | Finding | Fix | Commit |
|---|---------|-----|--------|
| 1 | **Animated sharing was broken on the live site.** `builder.html` is generated by `tools/build_shells.py`, which didn't list `videokit.js`, so the Studio threw "VideoKit is not defined" on load and on Share. | `videokit.js` added to the shell generator for the Studio, and Heard it live added as a generated page; regenerated. | f5e8a07 |

Used by the Studio, study, lessons and explorer. | d18386f |

### Checked and not bugs
- Links inside closed `<details>` (insights "more", Studio Motion) were reported as unnamed. Hidden elements; the checker now skips them.
- An earlier "248 speakers" count was the test counting the 8 hidden top-speaker buttons too. The real count is 240 everywhere.
- Moderation showed a 400 for a fake card image in the mocked run (test data only).
- The local test server was stopped twice by another process mid-run; affected runs were repeated on a private port.

## Known limits
- Native share sheets, the camera roll and the system print dialog can't be driven by automated tests; their calls were stubbed and the payloads checked (file type, size, dimensions, user-gesture timing).
- Lighthouse scores come from simulated slow 4G; the main cost is the 199 KB compressed study library, which loads only when needed.
